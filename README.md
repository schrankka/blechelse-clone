# Blechelse Clone

A lightweight, responsive train-announcement generator built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for GitHub Pages to publish the site.

Features include German and English announcement templates, editable train details, browser speech synthesis, copy-to-clipboard, and TXT export.

This is an independent community-style implementation and is not affiliated with Deutsche Bahn. It is not yet verified as a pixel-perfect 1:1 copy of the reference website.
